# 电气接线与信号架构说明

本文档说明基于 **STM32 Nucleo-F446RE** 的 Furuta 倒立摆平台电源分配、电机驱动与双编码器信号链路。

---

## 系统接线框图

```text
+-----------------------+       +---------------------------+       +---------------------+
|   直流主电源           |       |   电机驱动模块             |       |  12 V 直流减速电机   |
|   12 V / 3 A          |------>|   (TB6612FNG / H桥驱动)   |======>|  (减速比 9.267:1)   |
|                       |  GND  |                           | 功率线 |                     |
+-----------+-----------+  +--->| VM (电机电源)              |       +----------+----------+
            |              |    | GND (必须共地)             |                  |
            |              |    |                           |                  | 机械耦合
            v              |    | PWM  <-- TIM8_CH2         |                  v
+-----------+-----------+  |    | IN1  <-- PA10             |       +---------------------+
|   DC-DC 降压模块       |  |    | IN2  <-- PB3              |       |  旋臂 (Rotary Arm)  |
|   (MP1584EN: 5V/3.3V) |  |    +---------------------------+       +----------+----------+
+-----------+-----------+  |                                                   |
            |              |                                                   v
            v              |                                        +---------------------+
+-----------+-----------+  |    +---------------------------+       |  导电滑环            |
|   STM32 Nucleo-F446RE |  |    |  电机尾部编码器            |<------|  (6路中空, 内径5mm)  |
|                       |  |    |  (44 计数/圈)              |       +----------+----------+
```

## 关键集成注意事项

1. **共地要求**：12 V 电机电源地、降压模块地、编码器地与 Nucleo-F446RE `GND` 必须可靠共地。
2. **滑环防缠绕**：摆杆编码器的供电与 A/B 相信号通过中空导电滑环引出，使旋臂可连续 360° 无限旋转。
3. **电平转换**：5 V 编码器输出经双向电平转换模块降至 3.3 V 后再接入 STM32 定时器输入引脚。
4. **软件安全保护**：固件对 `TIM8_CH2` PWM 占空比设置了 `PWM_DUTY_SAFETY_CAP = 0.80` 上限，并支持通过板载蓝色按键 `PC13` 一键启停/急停。
