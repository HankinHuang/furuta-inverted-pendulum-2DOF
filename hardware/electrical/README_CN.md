- 中文接线说明：[hardware_notes_CN.md](hardware_notes_CN.md)

## 1. STM32F446RE 实机引脚与外设映射

与 `firmware/swingup_lqr/Core/Src/main.c` 及 `firmware/swingup_pid/Core/Src/main.c` 完全对齐：

| 功能 | 外设 / 引脚 | 说明 |
| :--- | :--- | :--- |
| **电机 PWM 输出** | `TIM8_CH2` | 周期 `4199`，软件占空比安全上限 `0.80`（`12.0 V` 供电） |
| **电机方向控制** | `PA10`、`PB3` | 互补数字方向输出（`GPIO_OUTPUT_PP`） |
| **电机轴编码器** | `TIM1`（`TI12` 四倍频正交解码） | 电机轴 `44` 计数/圈（配 `9.267:1` 减速箱） |
| **摆杆转轴编码器** | `TIM3`（`TI12` 四倍频正交解码） | `4096` 计数/圈，信号经导电滑环接入 |
| **串口遥测** | `USART2`（`115200` 波特率，8N1） | 每 `50 ms` 输出状态调试信息 |
| **启动 / 急停按键** | `PC13`（`B1_Pin`，`EXTI15_10`） | 下降沿外部中断，控制起摆启动与急停锁定 |

## 2. 物料清单（整理自 `electrical_components.doc`）

### 2.1 核心平台与 PCB 集成器件

| 器件类别 | 型号 / 规格 | 用途说明 | 状态 |
| :--- | :--- | :--- | :--- |
| **主控开发板** | STM32 Nucleo-F446RE | 1 kHz 实时控制核心 | 已确认 |
| **直流电机驱动** | TB6612FNG | 双路 H 桥 PWM + 方向驱动模块 | 已确认 |
| **DC-DC 降压模块** | MP1584EN | 将电源降压至 5 V / 3.3 V 逻辑供电 | 已确认 |
| **电源适配器** | 12 V / 3 A 直流电源 | 电机与系统主供电 | 已确认 |
| **导电滑环** | 6 路中空滑环（内径 5 mm） | 保证旋臂连续 360° 旋转而不缠线 | 已确认 |
| **电平转换模块** | 双向逻辑电平转换模块 | 将 5 V 编码器信号转换为 3.3 V STM32 电平 | 已确认 |
| **调试下载器** | ST-LINK | 固件烧录与在线调试 | 已确认 |
| **USB 转串口模块** | CH340 | 辅助串口调试通信 | 已确认 |

| **PCB 接插件与线束** | DC 电源座、SS-12D00G3 拨动开关、接线端子、SWD/UART 排针、杜邦线 | PCB 集成与模块连接 | 已确认 |
